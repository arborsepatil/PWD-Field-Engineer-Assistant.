# Public reference access — V35 verification

Scope: **PWD Field Engineer Assistant** shared Android app and public GitHub Pages build.

## Verified access policy

- The shared Library lists only official publisher sites and clearly distinguishes a book publication page, public index, catalogue and online portal. A portal/catalogue is **not** an entitlement to view every code or book free of charge.
- Publisher pages are linked using **View on publisher**; private Drive files and their file IDs are not available through shared app navigation or packaged APK assets.
- The latest privacy gate excludes private PDF readers, privately-derived bridge indexes, historical rule/red-book reading screens, and MoRTH excerpt modules from Android and public-site distribution. Their prior code may remain in Git revision history, so do not claim previous public code distribution was retroactively deleted.
- No PDF bytes are bundled, sold, published or served through public GitHub hosting. An official external site may allow a download; an app-side **View** link cannot technologically prohibit saving by the publisher's site.

## V35 access accuracy correction (23 Oct 2026)

A direct CPWD Civil Specifications Volume I PDF URL returned **Request Rejected** when independently tested. Rather than displaying it as an immediately viewable free book, V35 removes the direct link from the public list and retains the CPWD official publications catalogue with an access-limit explanation. The Bridge/Design category is confirmed to be linked from the Bridge screen and supported by the Library filters.

The authoritative editions of books and applicable amendments must always be confirmed from the publisher before use. Public access and current technical validity are separate questions.

## Remain private — no public redistribution implied

User-held PDF documents in Drive (BIS/IRC editions, bridge books, historical steel tables, PWD manuals, SSR, MoRTH and similar files) retain their existing access permissions. Private file names, IDs and personal Drive paths are intentionally excluded from this public project note and shared application.

## QA gate

- V33 catalog test: exact public listing count, source hosts, bridge/design category, and rejected CPWD URL exclusion.
- V34 privacy test: no private Drive/Sheets origins in distributed HTML/JS, restricted reader exclusion and common Android/Pages distribution rules.
- Android QA and the public static site build remain required; a successful build is not proof that every publisher URL stays available forever.
