Road & Structure Module

Step-by-Step Guide

Short instructions for normal work, mistakes, offline use and unusual cases.

1. Start work

Start a road inspection
1. Open Road & Structures.
2. Select your road.
3. Open Inspect.
4. Enter the current chainage or use the route/chainage tool.
5. Capture GPS if needed.
6. Tap Structure, Photo, Issue or Road Video as you work.
Change to another road
Finish or save the current item first. Open Roads, select the new road, then continue. Never save a structure under the wrong road just to save time.
Start midway, not from Ch. 0+000
Select the road and enter the actual chainage where you start. You do not need to begin from the road start.
Field rule: record what you know, leave unknown things blank, and never guess.

2. Register structures

New pipe culvert
Tap + Structure → Pipe Culvert. Enter number of pipes, pipe diameter, main barrel length if measured, headwall length if useful, condition and photos. Save. Construction year can be added later.
New box culvert
Tap + Structure → Box Culvert. Enter number of cells, clear width, clear height and overall length. Select condition, add photos and save.
New slab culvert
Select Slab Culvert. Enter spans/cells, clear width, clear height and overall length. Add condition and photos.
New causeway / vented causeway
Select Causeway or Vented Causeway. Enter overall length, roadway width, number of vents if present and vent size if known. Add photos and condition.
New bridge
Select Bridge, Minor Bridge or Major Bridge only when known. Enter start chainage, end chainage, span arrangement and approximate width. If classification is uncertain, choose Bridge and classify later.
Bridge abutment naming
Use start-side abutment and end-side abutment in field notes. If official drawing names A1/A2 are known, add them later. Avoid “left abutment/right abutment” unless direction is clearly defined.
New retaining wall
Select Retaining Wall. Enter start chainage, end chainage, approximate height and side (LHS/RHS). The structure is treated as a length, not just one point.
Unknown year or dimension
Leave it blank. Tap Save · Complete Later. At home/office, open the structure and use Edit / Complete Later.
Structure already exists in the app
Do not register it again. Open Structures, select the existing structure and tap Inspect.
Duplicate structure created by mistake
Do not continue adding inspections to both records. Keep the correct record and mark the duplicate for cleanup. A safe merge/delete control will be added after field testing.
Structure under construction
Register it with condition/status Under Construction. Add the basic dimensions that are already known and progress photos. Later use Lifecycle → Construction Completed.
Structure reconstructed
Open the old structure → Lifecycle → Reconstruction. The old history stays. The structure revision increases and permanent dimensions can be entered again for the reconstructed structure.
Structure widened
Open the structure → Lifecycle → Widening. Add a short note. If dimensions changed, update the permanent inventory after the widening is complete.
Structure repaired
Open the structure → Lifecycle → Repair / Rehabilitation. Add a short note and, when useful, new photos. Do not erase the earlier poor-condition inspection.
Structure removed or abandoned
Open the structure → Lifecycle → Removed / Abandoned. Keep the history. Do not delete the asset simply because it no longer exists.

3. Repeat inspection

Routine inspection of an existing structure
Open Structures → select the asset → Inspect. Select Good / Fair / Poor / Critical. Mark only issues actually observed. Add a short note/photo only if useful. Save.
Condition unchanged
Select the same condition, leave issue chips blank, add a photo only if you need current evidence, then save. Do not re-enter dimensions.
New crack / scour / blockage found
Inspect the existing structure, choose the correct condition, select the observed issue, take a clear photo, add a short note, and save.
Critical condition
Select Critical, take clear evidence photos, add a concise note and follow your departmental safety/escalation procedure. The app is a record; it does not replace engineering judgment or official action.
Missed a CD and remembered 1 km later
Keep the inspection active. Return safely by walking/vehicle. At the structure, correct the chainage, capture the CD, then continue. Do not stop and create a fake new survey just because you backtracked.
Wrong chainage entered
Open the item as soon as possible and correct it. If the permanent asset record is already created, use Edit / Complete Later. Future alignment-based chainage will reduce this problem.
Quick road issue, not a structure
Open Inspect → Issue. Choose pothole/surface damage, edge failure, settlement, waterlogging, drainage, shoulder erosion, landslide/slope issue, safety hazard or other. Add note/photo and save.
Quick photo only
Open Inspect → Photo. Take/select the photo, add a short caption if needed and save. The app links it to the selected road, chainage and GPS if captured.

4. Road video survey

Standard 1 km video survey
1. Mount/hold the phone safely before moving.
2. Start Road Video.
3. The app records video with GPS and chainage.
4. The recording is divided into 1 km stretches.
5. Mark important events such as pothole, edge failure, drainage issue or structure.
6. Finish the survey.
7. The report lists chainages and can jump directly to the matching video time.
Start video at Ch. 6+200
The first segment may be Ch. 6+200 to 7+000. After that, use full kilometre stretches such as 7+000–8+000, 8+000–9+000.
Reverse direction during video
The future alignment-based chainage engine will detect increasing/decreasing direction. Do not assume video time equals increasing chainage when you are travelling backward.
Important defect near kilometre boundary
Do not lose the event just to cut exactly at the kilometre mark. The app may allow a few seconds of overlap around the boundary while the report still uses the correct chainage.
Video file is large
Use Standard 1080p/30 fps for normal surveys and Economy 720p/30 fps for long surveys. Keep 1 km segments so files stay manageable. A high-detail mode should be used only when necessary.
Senior wants only one defect
Open the report and tap the event at that chainage. Playback should jump to that point in the matching 1 km video instead of making the senior watch the whole road.
Safety: do not operate the phone while personally riding/driving. Start recording before moving, stop safely for manual inputs, or use a passenger/operator.

5. Offline, photos and storage

No mobile network at site
Keep working. Structure data, inspections, issues and optimized photos save locally first. Internet is not required for ordinary field capture.
Photo size
The app reduces normal photos to about 1800 px maximum dimension with practical JPEG quality for storage. Use a future High-detail photo option only for cracks/details that need extra resolution.
Original phone photo
The working copy inside the app may be optimized. If you need the original high-resolution image for another purpose, keep the original in the device camera/gallery according to your project policy.
Low phone storage
Stop long video recording before the device becomes critically full. Sync/export completed work when possible and clear only data that has been safely backed up.
Sync failed
Do not re-enter the field work. The local record remains the primary copy until sync succeeds. Retry when the network is stable.
Phone restarted / app closed
Saved items remain in local storage. Reopen the app, select the road and continue. Unsaved form fields may be lost, so save a structure/inspection before moving away.

6. GPS and common problems

GPS accuracy is poor
Wait for a better fix if location matters. You may save by chainage and complete GPS later. Never treat phone GPS as survey-grade setting-out data.
GPS point jumps to side of road
Do not move the permanent asset just because of one bad fix. Capture a fresh fix. The planned master-alignment system will project the position to the road and show offset/LHS/RHS.
Wrong road selected
Do not keep adding data. Correct the road before continuing. If an asset was already saved under the wrong road, flag it for correction instead of duplicating it on the correct road.
Wrong structure type selected
Open Edit / Complete Later, change the structure type, and re-check the basic dimensions because the field labels will change.
Photo did not save
Confirm the photo appears in the preview before saving. If not, take/select it again. For an already saved asset, add the photo during the next inspection rather than recreating the asset.
Internet map unavailable
Continue with road/chainage/structure data. Satellite imagery is supplementary. Field capture must not stop because an online basemap is unavailable.

7. Complete at home / office

Complete missing inventory later
Open Structures → select asset → Edit / Complete Later. Add year, local/crossing name and any missing permanent dimensions. Save.
Add data from old register / drawing
Use the existing asset. Add verified permanent information to inventory. Do not create another asset just because the source is an old paper register.
Prepare report for senior
Use the inspection history/issues/photos. For road video, the report should list km/chainage-wise issues and provide Jump to Video links for each recorded event.
Export / backup
Use app export/sync when available. Keep structure inventory, inspection history and media linked by the structure ID so photos never become anonymous files.
Correct permanent inventory after reconstruction
First record Lifecycle → Reconstruction. Then update the new permanent dimensions. The previous revision stays in history.
Main idea: Permanent inventory once → repeat condition inspections → lifecycle history forever.
Engineering-use boundary: This app supports field documentation and asset management. Approved drawings, survey instruments, departmental records, project specifications and engineering judgment remain controlling.
