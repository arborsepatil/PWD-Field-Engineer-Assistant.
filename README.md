# PWD Field Engineer Assistant — V2

Mobile-first field engineering PWA for Maharashtra PWD site work.

## Deployment
- **GitHub:** version-controlled app source.
- **GitHub Pages:** free HTTPS static hosting.
- **Android:** install through Chrome after the live page is working.
- **Google Drive:** separate project reference library and release archive.

## Release boundary
This is a **public code/deployment repository**. Original reference PDFs, paid/licensed codes, PWD source scans, and drawing scans are **not published** here. A complete private/offline project release is retained in the owner's Drive. The public web build must not imply that a source-linked module is complete when its underlying source is withheld.

Source references, engineering guidance, and code editions must be checked against the project's approved and applicable documents before official use. First-pass Rule Book transcription is not independently verified text.
